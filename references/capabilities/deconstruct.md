# 拆文：只迁移抽象机制，不复刻表达

## R — 原文 (Reading)

> 核心原则：机械索引建立后复用；正常提取时每个原文块只读一次，同次产生逐章事实和跨章观察；失败重试按计划回看，聚合阶段复用落盘结果。
>
> — `zenstory-ai/oh-story-claudecode/skills/story-long-analyze/SKILL.md`·导语·核心原则

> 禁止：把拆书报告直接当大纲用；把原作角色关系图换名后直接用；把原作章节标题改一个字后复用。

> 角色替换为 [主角] [对手] [导师]，地名替换为 [初始势力] [高层地图]；情节替换为「动作 + 结果 + 代价」的功能描述
>

## I — 方法论骨架 (Interpretation)

拆文是把别人的成品逆向成「可复用结构」，不是做读书笔记，也不是换皮抄书。两个约束同时成立：

- **工程约束**：长文拆一次就够。先建章节索引，逐块读取时同次产出「逐章事实」与「跨章观察」，后续聚合只读落盘摘要，不重读原文；进度写状态文件，支持断点续跑。
- **版权/质量约束**：所有专名换成功能位占位符，情节改写成「动作＋结果＋代价」的功能描述；报告里最长连续重合要受限，专有名词零命中。

输出只有三类东西可交给下游：结构模板、节奏参数、功能位。-rated 评分必须附理由，因为「照搬会劝退读者，但局部技法高度可复用」。

## A1 — 应用案例 (Past Application)

**原仓库案例**：`oh-story-claudecode/README.md` 的拆文报告给出「立人设强、给爽点零」的评分结论，并明确只迁移「导师代言设定、延迟点名、身体反应外化」三项局部技法，不迁移整本书的三章结构。短篇拆文另把原文切成情节节点并标情绪强度（−9~+9）与手法。

**合成演练**：输入一段「宗门大比」→ 输出功能描述「[主角] 在公开场合被迫应战 → 结果：越级获胜并暴露[特殊能力] → 代价：被[高层势力] 标记」；专名全部占位符化，无原句残留。

## A2 — 触发场景 (Future Trigger) ★

### 情境
1. 想学某本爆款的结构，但不想抄。
2. 需要把对标书拆成「节奏参数」用于自己的大纲。
3. 已有旧稿，要逆向成可续写的工程（先走本卡，再走 `import-legacy`）。
4. 长篇对标书几十万字，需要不爆上下文地拆完。

### 语言信号
- "拆一下这本书 / 分析它为什么好看"
- "我想借鉴这个结构 / 提炼节奏"
- "把前 20 章反向解析成设定"
- "reverse-engineer this novel / extract the structure"

### 与相邻能力的区分
- 与 `trend-scan`：横向多书找重复模式 vs 纵向单书拆机制。
- 与 `import-legacy`：拆完仍是对标素材；只有明确要「续写自己的旧稿」才走导入，且导入源严禁登记为对标。
- 与 `outline-architecture`：本卡不产出卷纲，只产出可迁移的结构模板与节奏参数。

## E — 可执行步骤 (Execution)

### 输入契约
必需：待拆文本或可定位的章节清单；拆文目的（学结构 / 学节奏 / 逆向导入）。
缺失文本时停止，不得「凭记忆拆书」——这是仓颉流水线的硬红线。

### 步骤
1. **建索引**：生成章节索引（编号、字数、首末句定位）。完成标准：索引可随机访问任意章，不需要通读。
2. **黄金三章精读**：拆开局钩子、人设建立、追读理由。完成标准：每维给分并写依据。
3. **逐块提取**：每个原文块只读一次，同次产出「逐章事实」与「跨章观察」，事实附 5–15 字定位词。完成标准：缺失信息写「未知」，不补写。
4. **抽象化**：专名→功能位占位符，情节→动作＋结果＋代价。完成标准：专名零命中，最长连续重合不超过 12 字。
5. **落盘与复用**：写拆文报告与进度文件，聚合阶段只读落盘结果。完成标准：中断后可从进度文件续跑。

### 输出契约
拆文报告（评分＋依据＋可迁移技法清单）、结构模板、节奏参数。判停：出现「把原文换名直接用」倾向时立即停止并回到步骤 4。

## B — 边界 (Boundary) ★

- **禁止**把结果倒推成人物早有计划、把后验结果写成伏笔；区分「客观发生顺序 / 文本披露顺序 / 读者所知 / 角色所知」四条时间线。
- **禁止**复刻专有设定、角色组合、关键事件链、标志性场面或原句。
- 拆文报告不是大纲，不得直接进入写作。
- 原仓库明确：不得以「敏感」「不适」为由中断整篇只读的文学拆解；确无法处理的片段可跳过，其余照常完成。
- 无文本、只有书名时停下来要材料，不要编内容。
