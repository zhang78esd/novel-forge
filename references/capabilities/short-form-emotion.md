## I — 方法论骨架 (Interpretation)

短篇不是「缩小版长篇」。它不铺世界观、不跑多线、不建卷级循环，整篇只有**一个核心支点：要交付的那一种情绪**（意难平、反转震撼、爽感释放等）。流程是四阶段：先定目标情绪 → 构思故事核、反转、付费点 → 逐场景写作并过完成门槛 → 精修。

判断单位是「场景」而不是「章」。每个场景按情绪强度标注（−9~+9），检查情绪曲线是否朝目标推进；一个场景完成了职责就收，哪怕很短也不许加戏凑长度。故事核要能用一句话说清「谁在什么处境下、被什么反转击中」，付费点/翻转点必须落在情绪最强的那一拍之前。

## A1 — 应用案例 (Past Application)

**原仓库做法**：`oh-story-claudecode` 短篇线把原文切成情节节点 N1、N2…，每节点写「事件 + 情绪标签 + 强度值 + 手法」，例如「门口偷听到『私生子而已』·情绪{震惊}{−7}」。写作用单一核心支点、逐场景推进，不调用长篇的黄金三章与卷纲模型。

**合成演练**：目标情绪「意难平」→ 故事核「他替她顶了罪，出狱那天她已嫁给当年指认他的人」→ 情绪节点：期待 +3 / 撞见 −6 / 认出 −8 / 她递来一张旧车票 −9 → 付费点放在「认出」前一拍。

## A2 — 触发场景 (Future Trigger) ★

### 情境
1. 要写一篇短篇、盐选/短故事、爽文单篇。
2. 有反转点子，需要排情绪曲线与付费点。
3. 短篇写着写着变成世界观介绍。
4. 想给已有的短篇找「情绪不够」的原因。

### 语言信号
- "写个短篇 / 一篇爽文 / 短故事"
- "这个反转怎么安排 / 付费点放哪"
- "情绪不够 / 读完没感觉"
- "short story / twist / emotional beat"

### 与相邻能力的区分
- 与 `chapter-craft`：短篇不走章首引子七式与多弧并行；按场景与情绪节点走。
- 与 `trend-scan`：短篇扫榜看六种目标情绪，不看题材热度中位数。
- 与 `outline-architecture`：不建卷纲/细纲，只做故事核与情绪节点表。
- 与 `project-bootstrap`：短篇可跳过完整设定词典，只锁目标情绪与核心支点。

## E — 可执行步骤 (Execution)

### 输入契约
必需：目标情绪（六选一或用户自定）、篇幅上限。
若用户只给「一个点子」，先把它转成「一句话故事核」再继续；不愿选择目标情绪时给 3 个候选，不静默默认。

### 步骤
1. **定目标情绪**：明确读者合上屏幕时应该是什么感受。完成标准：可用一个词＋一句身体反应描述。
2. **写故事核**：主角处境、当前麻烦、反转、代价。完成标准：一句话说完，不出现势力/门派铺陈。
3. **排情绪节点**：切场景，每节点标情绪标签与 −9~+9 强度。完成标准：曲线朝目标情绪单调推进或有明确回落再冲高。
4. **定付费点/翻转点**：落在情绪最强拍之前。完成标准：翻转所需信息在前文已埋，不是空降。
5. **逐场景写**：每场景只服务目标情绪，完成即收。完成标准：无凑长度的任务卡点、对话、回忆、环境。
6. **精修**：删抽象情绪词，换成动作与物件。完成标准：不出现「五味杂陈」「空气凝固」类套话。

### 输出契约
故事核 + 情绪节点表 + 成稿。判停：用户只想聊「这个反转妙不妙」时，交付到步骤 4。

## B — 边界 (Boundary) ★

- **不要**用长篇的卷纲、黄金三章、伏笔三态台账套短篇，会稀释情绪密度。
- **不要**为凑字数加戏——原仓库把这条写成小节完整性流程的硬约束。
- **不要**把「目标情绪」写成主题思想（如「探讨人性」），必须是可感受的具体情绪。
- 反转不能靠机械降神：所需信息必须前文埋过。
- 情绪强度标注是诊断工具，不是「每节必须更惨」的配额。
